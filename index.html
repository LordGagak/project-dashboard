Connect Google Sheet

Buat Google Sheet dengan kolom berikut (urutan harus sama), lalu publish sebagai CSV dan paste URL-nya di bawah.

Kolom A: Request Name
Kolom B: Type (Photo / Video)
Kolom C: Status (Plan / On Progress / Delivered)
Kolom D: Date (format: DD MMM YYYY, contoh: 15 Jan 2025)
Kolom E: Notes
Kolom F: File Link (URL Google Drive)

Cara publish: File > Share > Publish to web, pilih sheet dan format CSV, klik Publish. Copy URL-nya dan paste di bawah.
